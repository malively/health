# Kanban

A drag-and-drop kanban board that assigns characters from the [Rick and Morty API](https://rickandmortyapi.com/) to tasks. Built with React, TypeScript, Vite, and `@dnd-kit`.

## Getting started

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Available scripts

- `npm run dev` — start the dev server with hot reload
- `npm run build` — type-check and build for production into `dist/`
- `npm run preview` — serve the production build locally

## Notes

The app fetches characters from a public GraphQL endpoint, so it needs internet access on first load.
